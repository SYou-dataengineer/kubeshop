# Sorties analytiques

Airflow génère ici les fichiers suivants après chaque traitement quotidien :

- `product_metrics.csv` : agrégats Batch par produit;
- `daily_sales.csv` : ventes agrégées par journée;
- `weekly_sales.csv` : ventes agrégées par semaine, du lundi au dimanche;
- `monthly_sales.csv` : ventes agrégées par mois civil;
- `dashboard_kpis.csv` : indicateurs globaux pour Power BI;
- `product_analytics.csv` : vue consolidée Batch + temps réel;
- `recommendations.csv` : classement et actions recommandées;
- `dashboard_summary.json` : source du tableau de bord Web.
